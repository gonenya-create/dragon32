What we are building now

The Dragon machine is a Dragon 32 whose chips are emulated in your browser: the 6809 CPU, memory, video and cassette, through Ciaran Anscomb's XRoar emulator. The ROM, the chip that holds the BASIC language, belongs to its rights holders. So we are writing our own ROM in the 6809's machine language.

The goal

The real computer, as close as we know how, without copying the original code. Every decision is judged by one question: does this bring us closer to the original?

How we are building it

  • The core: the BASIC that Microsoft published as open source (MIT licence). It gives us numbers, strings, variables and loops.
  • Two rooms: I'm not a programmer; I build with AI. One AI agent reads the original and reports only facts, in its own words: what each command does, and at which memory addresses. A second agent writes the code without ever seeing the original. Behaviour as close to the original as we know how, our own code.
  • The books of the time: the manuals that came with the computer and BASIC books from those years.
  • The emulator's author: Ciaran Anscomb answered questions no book answers, such as the exact cassette speed.

How we test it

574 automatic tests run the ROM inside XRoar on every change. They check what appears on the screen, what is written to tape and what goes to the printer. Among them are 74 programs from old BASIC books, with the output printed in the book, and sound down to the CPU cycle.

What there is today

  • The whole BASIC in one 16K chip, as in the original. The cartridge slot stays empty.
  • All the commands, with the same error messages: graphics, sound and PLAY, EDIT and RENUM.
  • Cassette in the original format and at the original speed, including files.
  • Printer: LLIST and PRINT #-2.
  • RESET keeps your program, and BREAK stops with the line number.
  • 25 extension hooks in memory, in the same places as the original. Cartridges add commands through them.

What is still far from the original

  • Machine-code software: many old games jump straight to addresses inside the original ROM. We built the addresses that software of the time used, each in its original place, and the command tables too. 23 games from that time already run on it without any change to their code, by Ken Kalish, Scott Adams, Mike Hughey, Tim Love, Harry Whitehouse and Ian Murray-Watson, with their authors' permission. The next step: comparing it with a real Dragon.
  • Speed: a BASIC program runs at a slightly different speed from the original. We have not measured by how much yet.
  • DLOAD: loading over a cable. We do not know yet what it does on a Dragon 32.
  • A real machine: we have not checked against a real Dragon yet. Everything we know comes from the original, the books and Ciaran.

This is a hobby project with no timetable. What we build here does not change the main app.

Do you have a real Dragon?

Some things can only be learned from a working machine. Please type these lines and tell us what appeared on the screen, and which model:

  • PRINT PEEK(144)*256+PEEK(145) (the length of the tone at the start of every tape)
  • PRINT PEEK(287) (one memory value we do not know)
  • 10 REM then LLIST, with no printer connected (does OK appear, or does it hang? RESET brings it back)
  • DLOAD (an error, nothing, or a hang?)
