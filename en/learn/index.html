The Learning Corner

Machine code from zero · 16 chapters

The Dragon's processor does not understand BASIC. It only understands numbers. In this course you learn to speak its own language, machine code, from the very first step: what memory is, how a letter appears on the screen, loops, keys and movement. At the end you build a whole game: a basket that catches falling apples.

The course is for kids, teens and adults, including people who never wrote a line of code. Each chapter is short, with drawings, a window that runs the program line by line, questions and puzzles. You can stop anywhere: the browser remembers which chapters you finished.

Every program was checked on the site's Dragon machine. And in the last chapters one button sends your program to the machine, where it runs just like in 1982.

Don't know BASIC yet? You can start with the BASIC lessons, but you don't have to.
