Accessibility statement

We want everyone to be able to come to Dragon 1982, write BASIC and play. The site was made accessible following the Israeli standard IS 5568 (based on the international WCAG guidelines), at level AA, as far as possible for a site that recreates a 1982 computer.

What we did

  • Keyboard only: every button, tab and card works with Tab, Enter and Space, with a clear focus outline. You move between tabs with the arrow keys. While the computer is open, the guide behind it doesn't "steal" the focus.
  • Screen readers: every button and field has a name. What the computer prints after each command is read out briefly. Errors are explained in a "What happened?" box.
  • Language and direction: the text on the computer screen, the code and the keyboard are marked as English, so they are read aloud in English. The Hebrew version of the site is marked as Hebrew, right to left.
  • Contrast: text and background colours meet the required contrast level. Checked with an automated tool (axe) in all the main states, on computer and phone.
  • Motion: if your device asks to "reduce motion", you get fast typing, no flicker on the TV screen and no animations.
  • Size: you can zoom the page in your browser (up to 200%), and the computer adapts to the window size.
  • Without typing: ready-made commands at a click, a drawn keyboard on the screen, and a helper that answers questions.

What is still limited

  • The cartridge games and the drawings are graphics drawn on the screen (as on the original computer), so they can't be played with a screen reader. They can be played with the keyboard alone. The cassette games (like "Guess the number" and "Moon lander") are text, and they are accessible.
  • The Dragon machine (being built) shows the computer screen as a picture, like a TV, so a screen reader cannot read it. You can type into it with the keyboard after clicking the screen or moving to it with Tab. Screen-reader users can use the app, where everything on the screen is read out.
  • The drawn keyboard is meant for touch and mouse. Keyboard and screen-reader users type straight into the command line.
  • The computer screen shows only capital letters, as on the original. To see them larger, zoom the browser or switch to "Screen only".

Found a problem?

If something isn't accessible to you, we'd like to know and fix it. Accessibility coordinator: Gonen Yarom. You can reach him through the contact page (in Hebrew; writing in English is fine). Please mention which page, what you were trying to do, and which device and browser.
