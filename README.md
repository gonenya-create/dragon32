# Dragon 32 · 1982

A tribute to the **Dragon 32** home computer (Wales, 1982), running in the browser:
a green screen, a BASIC to write your own programs, tapes, original cartridge games in the spirit of the time,
programmer tools and an AI helper. Installable as an app.

**https://dragon1982.com**

- Everything in the app is our own: the BASIC interpreter, the games, the graphics and the texts.
  No original ROM is used.
- **The Dragon machine** ([/lab/1982](https://dragon1982.com/lab/1982/), being built): our own 16K 6809 BASIC ROM (`rom/`)
  running on Ciaran Anscomb's [XRoar](https://www.6809.org.uk/xroar/) emulator (GPL v3, see `lab/1982/SOURCE.md`).
  Its core is translated from the 6502 BASIC that Microsoft released as open source (MIT licence, `rom/mit/`).
  It contains no code from the Dragon ROM.
- Era software from other authors appears only with the author's written permission, credited by name.
- Games by other authors on the Dragon machine's tape shelf, each under its author's own terms (not ours), with its documentation alongside:
  - **Blockdown** by Ciaran Anscomb (2021): "Redistribution encouraged! Just be sure to include the documentation" — `lab/1982/tapes/blockdown.html`, https://www.6809.org.uk/blockdown/
  - **DragonTet** v1.1 by Salva Kantero (2025): GPL v3 — `lab/1982/tapes/dragontet-readme.txt`, `dragontet-license.txt`, source https://github.com/salvakantero/Dragontet
  - **Escape** (his first game, Color Software Services, 1982), **Phantom Slayer**, **Danger Ranger**, **Cuthbert in the Jungle** (his Trapfall, Tom Mix Software, 1983), **Dungeon Raid** and **Athletyx** by Ken Kalish (Med Systems; Dragon versions Microdeal, 1982–85; Dungeon Raid and Athletyx were written only for the Dragon): shared with permission. Ken Kalish wanted his Dragon and CoCo games to be freely available (via L. Curtis Boyle, http://www.lcurtisboyle.com/nitros9/interview.html). Removed on request.
