# פקודות נוספות ומערכים מספריים

המימוש נכתב מאפס בקובץ ⁨`src/stmt2.s`⁩. הקבצים ⁨`basic.s`⁩ ו־⁨`interp.s`⁩ לא שונו, בהתאם להגבלת המשימה.

## המימוש

פקודות ⁨`GOSUB`⁩ ו־⁨`RETURN`⁩ משתמשות ברשומות מחסנית הלולאות: שם אפס מזהה תת־שגרה; היסטים ⁨12⁩ ו־⁨14⁩ שומרים את הרשומה ואת מצביע ההמשך. החזרה מסלקת לולאות פנימיות ואינה מדליקה את דגל הקפיצה.

פקודת ⁨`ON`⁩ סורקת את כל רשימת היעדים לפני הקפיצה, כדי שחזרה מתת־שגרה תמשיך אחרי הרשימה. בחירה באפס או מעבר לאורך הרשימה אינה קופצת. מספר שלילי או גדול מ־⁨255⁩ מחזיר שגיאת תחום.

סריקת הנתונים עוברת רק בתחילות פקודות, מדלגת על הערות ועל מפרידים בתוך מירכאות. הפריטים המספריים נקראים בלי להעריך ביטויים. פריט במירכאות מגיע לנקודת הרחבה מסומנת ומחזיר כרגע שגיאת טיפוס. פקודת השחזור יכולה להתחיל מהשורה המבוקשת או מהשורה הבאה אחריה אם המספר אינו קיים.

המערכים נשמרים ברצף אחרי הסקלרים, לפי המבנה שנדרש במשימה. גדלי הממדים כוללים את איבר האפס. סדר האיברים במערך דו־ממדי הוא שורה אחר שורה, כשהאינדקס השני משתנה מהר יותר. שם המערך והאינדקס הראשון נשמרים במחסנית המעבד בזמן הערכת אינדקסים נוספים; כך אפשר להשתמש במערכים בתוך אינדקסים. החיפוש בכתובות המערכים מתבצע רק אחרי ההערכה, משום שיצירת סקלר עשויה להזיז אותם.

## זיכרון

האזור ⁨`$C0–$CF`⁩ משמש זמנית בלבד, אחרי סיום הערכת האינדקסים:

- שם, מספר ממדים ומצב הפעולה: ⁨`$C0–$C3`⁩.
- שני גדלים: ⁨`$C4–$C7`⁩.
- שני אינדקסים: ⁨`$C8–$CB`⁩.
- אורך ההקצאה וסופה: ⁨`$CC–$CF`⁩.

האזור ⁨`$03E0–$03E8`⁩ שומר את מצב קריאת הנתונים:

- מצביע הטקסט: ⁨`$03E0–$03E1`⁩.
- רשומת השורה: ⁨`$03E2–$03E3`⁩.
- דגל קריאה מתוך פקודת נתונים: ⁨`$03E4`⁩.
- סוף התוכנית וחתימת אתחול: ⁨`$03E5–$03E8`⁩.

יתר האזור שהוקצה למשימה פנוי. גם נתוני העבודה המקוננים נשמרים במחסנית המעבד הקיימת.

## שלוש נקודות שילוב נדרשות במפרש

אלה שינויים נדרשים בקובץ ⁨`src/interp.s`⁩, שלא בוצעו משום שהמשימה אוסרת לערוך אותו.

### איפוס קריאת הנתונים

בשגרת ⁨`clrvars`⁩, אחרי השמירה ל־⁨`FORSP`⁩ ולפני החזרה, יש להוסיף:

```asm
        lbsr st2_reset
```

השגרה כבר קיימת במימוש החדש ואינה משנה את מצביע הטקסט. היא משנה את האוגר הזוגי ואת דגלי התנאי. הקריאה נחוצה גם באתחול וגם לפני כל הרצה מחדש ועריכת תוכנית. מנגנון האתחול העצל מזהה שימוש ראשון ושינוי באורך התוכנית, אך אינו תחליף לקריאה הזאת.

ללא השילוב, התוכנית הבאה מדפיסה את הערך בהרצה הראשונה ומחזירה שגיאת סוף נתונים בשנייה:

```basic
10 DATA 5
20 READ A:PRINT A
RUN
RUN
```

### יעד השמה שמוזז בזמן הביטוי

השגרה הקיימת ⁨`do_let`⁩ שומרת כתובת מוחלטת של היעד לפני הערכת צד ימין. אם היעד הוא איבר מערך, ויצירת סקלר חדש בצד ימין מזיזה את המערכים, הכתובת שנשמרה אינה תקפה. לדוגמה:

```basic
DIM A(2):A(0)=Z+7:PRINT A(0);Z
```

המקרה הזה עלול להשחית את כותרת המערך. יצירת סקלרים בפקודות נפרדות אחרי מערך פועלת ונבדקת.

יש להחליף את גוף ההשמה, מהקריאה ל־⁨`getvar`⁩ ועד השמירה, במבנה הבא. הוא שומר את בסיס המערכים רק אם היעד נמצא במערך, ומחשב מחדש את כתובת היעד אחרי הערכת צד ימין:

```asm
        lbsr getvar
        ldy #0
        cmpu VARTOP
        blo 1F
        ldy VARTOP
1       pshs y,u
        lda #'=
        lbsr expect
        lbsr rexpr
        puls y,u
        cmpy #0
        beq 2F
        pshs y
        ldd VARTOP
        subd ,s++
        leau d,u
2       lbra stfac
```

המספרים המקומיים בדוגמה דורשים התאמה אם מוסיפים קוד נוסף באותה שגרה. אם נוסף מסלול השמה למחרוזות במקביל, יש להחיל את תיקון הכתובת על מסלול ההשמה המספרי בלבד.

### לולאה בתת־שגרה עם שם משתנה חיצוני

בשגרת ⁨`st_for`⁩, החיפוש הקיים אחר לולאה באותו שם מתחיל בתחתית המחסנית. כך הוא יכול לחצות מסגרת חזרה ולמחוק אותה. שחזור:

```basic
10 FOR I=1 TO 2:GOSUB 100:NEXT:END
100 FOR I=1 TO 2:NEXT:RETURN
RUN
```

כיום מתקבלת שגיאת חזרה ללא תת־שגרה. יש להחליף את מקטע החיפוש בלבד, לפני בדיקת גלישת המחסנית, בחיפוש לאחור שעוצר במסגרת החזרה הקרובה:

```asm
        ldy FORSP
1       cmpy #FORBASE
        bls 2F
        leay -FORLEN,y
        ldd ,y
        beq 2F
        cmpd FORNAME
        bne 1B
        sty FORSP
2       ldy FORSP
```

משם ממשיכים בבדיקת הגלישה ובבניית הרשומה הקיימות. משתנה הלולאה עדיין משותף, כמקובל במפרש הזה; התיקון שומר על מסגרת החזרה.

## בדיקות

בדיקות ההתנהגות נוספו לקובץ ⁨`tools/test.mjs`⁩, באמצעות האמולטור והכלי הקיימים. הן מכסות קינון וחזרה, חריגת מחסנית, בחירת יעד, טווחים, סריקת נתונים, שחזור, שגיאות, מערכים בשני ממדים, אינדקסים מקוננים, ממד אפס, הקצאה אוטומטית והזזת מערכים בעקבות יצירת סקלרים בפקודות נפרדות.

דוגמאות השילוב לעיל הן מגבלות ידועות של המפרש הקיים, ואינן נכללות כבדיקות עוברות. אחרי שילוב השינויים יש להוסיף אותן כבדיקות נסיגה, עם ציפייה לקריאה מוצלחת בשתי ההרצות, להדפסת ⁨7⁩ ו־⁨0⁩ בהשמה, ולחזרה תקינה גם כאשר שתי לולאות משתמשות באותו שם.
