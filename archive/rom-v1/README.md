# Dragon 1982 BASIC ROM (ניסוי)

BASIC משלנו למעבד 6809, שנטען במקום ה-ROM המקורי של ה-Dragon 32 (16K ב-$8000) ורץ באמולטור XRoar.

- **בנייה:** `rom/build.sh` (צריך `asm6809`: `brew install asm6809`).
- **בדיקות:** `node rom/tools/test.mjs` (צריך `xroar`: `brew install xroar`). הכלי בונה עותק זמני של המקור עם קלט בתור, מריץ את XRoar בלי חלון וקורא צילום מצב. אין צורך בבנייה מוקדמת ואין ניסיונות חוזרים. בדיקות התשתית: ⁨`node --test rom/tools/xr-test.mjs`⁩.
- **מסך ידני:** `xroar -machine dragon32 -extbas rom/build/d32.rom -cart d32x -cart-type rom -cart-rom rom/build/d32x.rom -no-cart-autorun` (השבב השני, `d32x.rom`, הוא ההרחבה בחריץ המחסנית: פקודות שלא נכנסו ב-16K).
- **מקור:** הכול נכתב מאפס. פורמט המספרים והאלגוריתמים לפי BASIC-M6502 של Microsoft (רישיון MIT, `LICENSE-MSBASIC`). אין כאן שום קוד או נתונים מה-ROM המקורי של Dragon Data או Microsoft.


כלי ההרצה המשותף הוא ⁨`rom/tools/xr.mjs`⁩. הפונקציה ⁨`runRom(lines, opts)`⁩ מחזירה ⁨`{ ram, screen, pia1b }`⁩: זיכרון של ⁨32768⁩ בתים, מסך מפוענח של עד ⁨16⁩ שורות (שורות ריקות בסוף מוסרות), ואוגר הפלט של ⁨PIA1 B⁩. כל שורת קלט מקבלת ⁨CR⁩; המגבלה הכוללת היא ⁨255⁩ בתים. נדרשים תווי ⁨ASCII⁩ מודפסים.

ברירת המחדל עוצרת ב־⁨`gk_scan`⁩, כשהקלט נגמר. האפשרות ⁨`trapSym`⁩ בוחרת סמל אחר, ו־⁨`range`⁩ בוחרת פגיעה לפי התחביר ⁨`M`⁩ או ⁨`M-N`⁩ של האמולטור. האפשרות ⁨`timeout`⁩ מגבילה את הזמן המדומה (ברירת מחדל: ⁨5⁩ שניות); ⁨`wallTimeout`⁩ מגבילה כל תהליך בזמן אמיתי (⁨20000⁩ אלפיות השנייה). קלט שלא מגיע לעצירה, למשל לולאה אינסופית, מחזיר שגיאה ברורה. הקבצים הזמניים נמחקים גם בכישלון; קובצי ⁨`rom/src`⁩ אינם משתנים.

לקריאת מסך מהירה:

```sh
node rom/tools/screen.mjs 'PRINT 2+3'
node rom/tools/gfxshot.mjs 'PMODE 4,1|PCLS 0|PSET(0,0)'
GFX_ACTIVE=1 node rom/tools/gfxshot.mjs 'PMODE 4,1|SCREEN 1,1'
```

הארגומנט השני בכלים האלה הוא זמן מדומה מרבי בשניות. הכלים בונים את העותק הזמני בעצמם; הם אינם מקבלים עוד נתיב ל־ROM בנוי.


מגבלה קיימת במקור: שגרת ⁨`getkey`⁩ ב־⁨`boot.s`⁩ מזיזה רק ⁨250⁩ תווי תור. הכלי מאפשר לייצר טבלה עד ⁨255⁩ בתים כנדרש, אך קלט מעל ⁨250⁩ בתים עלול להשתבש בזמן צריכתו. בניסוי עם ⁨246⁩ שורות ריקות ו־⁨`PRINT 42`⁩ (בסך הכול ⁨255⁩ בתים) הפקודה השתבשה ל־⁨`PRINNNNNN`⁩. המקור לא שונה. הבדיקות משתמשות בקלט של עד ⁨250⁩ בתים בכל הרצה.

תמיכה בקלטות: ⁨`CSAVE`⁩, ⁨`CLOAD`⁩, ⁨`MOTOR`⁩ ו־⁨`AUDIO`⁩ פועלות דרך אות הקלטת של החומרה המדומה. פרטי הפורמט, מגבלות ותוצאות הבדיקות ב־[תיעוד הקלטות](docs/tape.md). בדיקות הקלטת: ⁨`node rom/tools/tape-test.mjs`⁩; הן נכללות גם בחבילת הבדיקות המלאה.
