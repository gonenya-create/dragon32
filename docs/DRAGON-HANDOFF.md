## כלים (`rom2/`, בענף `d32/stage1`)
- **בנייה:** `sh rom2/build-s1.sh` מדפיס את הגודל. צריך `asm6809` ו-`python3`.
- **בדיקות:**
  - `node rom2/tools/s1-test.mjs`
  - `node rom2/tools/known-test.mjs rom2/tools/known.json <קובץ-תוצאה>`
  - `node rom2/tools/gfx-test.mjs`, `gfx-test-circle.mjs`, `gfx-test-draw.mjs` (`SEED=n` לסדרה אחרת)
- **רגרסיה:** `cd rom2/tools && node reg.mjs reg-base.json` צריך להדפיס `REG OK` (מספרים, מתמטיקה, מחרוזות).
- **תמונה מזיכרון המסך:** `cd rom2/tools && node shot.mjs out.png`.
- **הרצת ה-ROM:** `xr2.mjs` (`runRom(lines, opts)`) מחזיר מסך וזיכרון.
- **ב-worktree חדש** צריך קישור ל-`node_modules`: `ln -s ~/Projects/dragon32/tools/node_modules tools/node_modules`, ולמחוק אותו לפני commit.
