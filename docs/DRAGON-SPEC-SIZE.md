# מפת הגודל של ה-ROM המקורי — דוח הקורא, 20.10.2026

משמש כתקציב: כמה מקום כל חלק תופס במקור, מול שלנו. מספרים בלבד, בלי קוד.

**התוצאה: מתוך 16,384 בתים, הרשימות מקצות 16,329 בתים לקוד ולנתונים, ומשאירות 55 בתים כרווחי כתובות.** זהו מיפוי של Dragon 64 במצב 32K, בלי לקרוא קובץ ROM ובלי לשנות קבצים בפרויקט.

הסימונים בדוח:

- **(א)** מדידה ישירה של כתובות וגדלים ברשימות.
- **(ב)** חלוקה משוערת לפי תפקיד. גודל הטווח מדוד, אבל שיוכו לתכונה מסוימת הוא החלטת מיפוי.
- **(פתוח)** דבר שהרשימות לבדן אינן מוכיחות.

כל הכתובות הקסדצימליות; הגדלים בבתים עשרוניים. **כתובת הסיום כלולה בטווח.** המקור מקובע לגרסה ⁨`d1114864`⁩. הכתובות היחסיות ברשימות תורגמו לכתובות ROM לפי [סדר הקישור של מצב 32K][order].
