# התנהגות פונקציות BASIC — דוח הקורא

**זהו דוח מקור עם פערים מפורשים, ולא מפרט תאימות סגור ל־⁨Dragon 32⁩.** המאגר שנבדק מכיל מקור של ⁨Dragon 64⁩, לרבות מצב ⁨32K⁩; אין בו מקור נפרד שמוכיח את התנהגות ⁨D32⁩. **(ב)** [זהות המקור][readme]

קראתי את מסמכי הפרויקט המבוקשים. העבודה הייתה בקריאה בלבד, בענף ⁨`d32/stage0`⁩; לא נוצר או שונה קובץ, ולא נפתח ROM או פירוק שלו.

**סימונים:**

- **(ב)** — עובדה מן המקור שפורסם. התאמתה ל־⁨D32⁩ עדיין פתוחה.
- **(ב־שחזור)** — כתובת או תצורה מקובץ ההגדרות המשוחזר שבמאגר.
- **פתוח** — לא הוכרע; אין להשלים לפי התנהגות של BASIC אחר.
- לא הוספתי סימון **(א)** לטענה שלא בדקתי מחדש בספר.

**מגבלת הדיוק:** שיטות החישוב והחריגים להלן נבדקו במקור, אך לא הופקה טבלת תוצאות בת חמישה בתים לכל קלט. גם רשימת הכתיבות לכל בית עבודה אינה מלאה. הפערים האלה מסומנים, עם ניסויי הכרעה בסוף.

## 1. פונקציות מספריות והאופרטור ⁨`^`⁩

### תחומים, תוצאות ושגיאות

**(ב)** התוצאות להלן הן ערכים מספריים. רווח מוביל, סימן מינוס וכתיב מדעי שייכים להמרה לטקסט, ולא לערך המספרי עצמו. מצבר העבודה ⁨FAC⁩ שונה מהמספר הדחוס בן חמשת הבתים שבמשתנה. [טעינת מספר][fac], [המרה לטקסט][format]

| פונקציה | ארגומנט מספרי ותוצאה | שגיאות |
|---|---|---|
| ⁨`SGN(x)`⁩ | **(ב)** כל מספר מיוצג; מחזירה ⁨`-1`⁩, אפס או 1 לפי הסימן. | אין שגיאת תחום מספרית; מחרוזת מגיעה ל־⁨`TM`⁩. [מקור][sgn] |
| ⁨`INT(x)`⁩ | **(ב)** כל מספר מיוצג; השלם הגדול ביותר שאינו גדול מהארגומנט. למשל ⁨`INT(-2.75)=-3`⁩. אינה מוגבלת לשלֵם בן 16 סיביות. | מחרוזת מגיעה ל־⁨`TM`⁩. [מקור][int] |
| ⁨`ABS(x)`⁩ | **(ב)** כל מספר מיוצג; הערך המוחלט. | אין שגיאת תחום מספרית; מחרוזת מגיעה ל־⁨`TM`⁩. [מקור][sgn] |
| ⁨`FIX(x)`⁩ | **(ב)** כל מספר מיוצג; קיטום לכיוון אפס. למשל ⁨`FIX(-2.75)=-2`⁩, ⁨`FIX(-.1)=0`⁩. | אין הגבלת 16 סיביות; מחרוזת מגיעה ל־⁨`TM`⁩. [מקור][fix] |
| ⁨`SQR(x)`⁩ | **(ב)** מספר לא־שלילי; אפס מחזיר אפס. | שלילי גורם ⁨`FC`⁩. [מקור][power] |
| ⁨`LOG(x)`⁩ | **(ב)** מספר חיובי; קירוב ללוגריתם הטבעי. | אפס או שלילי גורמים ⁨`FC`⁩. [מקור][log] |
| ⁨`EXP(x)`⁩ | **(ב)** קירוב ל־⁨`e^x`⁩. תת־זרימה במסלול הרגיל מחזירה אפס. | גלישת ביניים או תוצאה גורמת ⁨`OV`⁩. גם קלט שלילי עצום עלול לגלוש בכפל הראשון. **פתוח:** ספי הקלט העשרוניים המדויקים. [מקור][exp], [גלישה][overflow] |
| ⁨`SIN(x)`⁩ | **(ב)** זווית ברדיאנים; קירוב לסינוס. אין בדיקת תחום זווית מפורשת. | בזוויות גדולות הדיוק תלוי בצמצום הטווח בחשבון BASIC. אין להסיק תוצאה מדויקת מספריית המתמטיקה של המחשב המארח. [מקור][sin] |
| ⁨`COS(x)`⁩ | **(ב)** זווית ברדיאנים; הוספת חצי π ואז שימוש בסינוס. | מגבלות הדיוק של צמצום הטווח חלות גם כאן. [מקור][cos] |
| ⁨`TAN(x)`⁩ | **(ב)** זווית ברדיאנים; חלוקת הסינוס בקוסינוס המחושבים. | קוסינוס **מחושב** ששווה לאפס גורם ⁨`OV`⁩, ולא ⁨`/0`⁩. גם מנה גדולה מדי גורמת ⁨`OV`⁩. [מקור][tan] |
| ⁨`ATN(x)`⁩ | **(ב)** כל מספר מיוצג; קירוב לארקטנגנס ברדיאנים. | אין בדיקת תחום מספרית נפרדת. בקלט גדול התוצאה יכולה להתעגל לקבוע המיוצג של חצי π; אין להבטיח תחום פתוח בקצה. [מקור][atn] |

**(ב)** בדיקת הטיפוס הכללית נעשית **אחרי הפעלת הפונקציה**. לכן אין כלל שלפיו מחרוזת גורמת תמיד ל־⁨`TM`⁩ לפני כל פעולה אחרת. בפונקציות המורכבות עלולה להתרחש קודם שגיאה חשבונית לפי שאריות ⁨FAC⁩. **פתוח:** השגיאה הראשונה המדויקת לכל שילוב של מחרוזת ומצב קודם. [שיגור ובדיקת טיפוס][dispatch], [בדיקת טיפוס][typecheck]

**(ב)** שגיאות בהערכת הארגומנט עצמו, כגון חילוק באפס, עשויות להתרחש עוד לפני הכניסה לפונקציה. תחביר חסר יכול לגרום ⁨`SN`⁩. רשימת שגיאות התחום בטבלה אינה מבטלת שגיאות אלה. [הערכת ביטוי ותחביר][syntax]

### שיטות החישוב

| פעולה | השיטה במילים |
|---|---|
| ⁨`LOG`⁩ | **(ב)** מפרידים מעריך בינרי ומנטיסה בטווח מחצי ועד פחות מאחד; משנים משתנה בעזרת שורש חצי ושורש שתיים; מחשבים פולינום אי־זוגי בעל ארבעה מקדמים; משלבים את המעריך ומכפילים בלוגריתם הטבעי של 2. [מקור][log], [הערכת פולינום][poly] |
| ⁨`EXP`⁩ | **(ב)** מכפילים בלוגריתם של ⁨e⁩ בבסיס 2, מפרידים שלם ושבר, מחשבים פולינום מדרגה 7 בעל שמונה מקדמים, ומשלימים באמצעות שינוי המעריך הבינרי. [מקור][exp] |
| ⁨`SIN`⁩ | **(ב)** מחלקים ב־2π, מסירים מחזורים שלמים, מקפלים לפי רבעי המעגל ומחשבים פולינום אי־זוגי עד חזקה 11, בעל שישה מקדמים. [מקור][sin] |
| ⁨`COS`⁩ | **(ב)** הסטת הזווית בחצי π ושימוש במסלול הסינוס; אין טבלה עצמאית. [מקור][cos] |
| ⁨`TAN`⁩ | **(ב)** משתמשים במסלול הסינוס ובזווית המצומצמת לקבלת סינוס וקוסינוס, ואז מחלקים. [מקור][tan] |
| ⁨`ATN`⁩ | **(ב)** עובדים על הערך המוחלט; בגודל שאינו קטן מ־1 משתמשים בהופכי. מחשבים פולינום אי־זוגי עד חזקה 23, בעל 12 מקדמים; משלימים ביחס לחצי π ומשחזרים סימן. [מקור][atn] |
| ⁨`SQR`⁩ ו־⁨`^`⁩ | **(ב)** משתמשים בלוגריתם, כפל ואקספוננט. שורש הוא מסלול חזקה עם מעריך חצי, **לא שיטת ניוטון**. גם חזקה שלמה אינה מסלול של כפל חוזר. [מקור][power] |

**(ב, השוואה מספרית)** טבלאות המקדמים זהות לטבלאות בענף **חמשת הבתים**, ⁨`ADDPRC≠0`⁩, של ⁨BASIC-M6502⁩:

| טבלה | מספר מקדמים | תוצאת ההשוואה |
|---|---:|---|
| ⁨`LOG`⁩ | 4 | זהים. [Dragon][log], [Microsoft][mlog] |
| ⁨`EXP`⁩ | 8 | זהים. [Dragon][exp], [Microsoft][mexp] |
| ⁨`SIN`⁩ | 6 | זהים. [Dragon][sin], [Microsoft][msin] |
| ⁨`ATN`⁩ | 12 | זהים. [Dragon][atn], [Microsoft][matn] |

**אין ערכי מקדמים שונים לדווח.** אין להשוות לענף ארבעת הבתים ולהסיק ממנו הבדל.

**פתוח:** זהות המקדמים אינה מוכיחה תוצאה זהה בכל סיבית. למשל, מסלול הטיפול בדיוק הנוסף ב־⁨`EXP`⁩ שונה לפני הפרדת השלם והשבר. [Dragon][exp], [Microsoft][mexpround]

### מקרי החזקה

כל השורות הבאות הן **(ב)** לפי [מסלול החזקה][power].

| מצב | תוצאה |
|---|---|
| מעריך אפס, כולל ⁨`0^0`⁩ | 1 |
| בסיס אפס, מעריך חיובי | 0 |
| בסיס אפס, מעריך שלילי | ⁨`/0`⁩ |
| בסיס שלילי, מעריך שאינו שלם | ⁨`FC`⁩ |
| בסיס שלילי, מעריך שלם רגיל | גודל דרך ⁨LOG/EXP⁩; סימן לפי זוגיות המעריך |
| בסיס חיובי | ⁨LOG⁩, כפל במעריך, ⁨EXP⁩; גלישת ביניים או תוצאה עשויה לגרום ⁨`OV`⁩ |

**(ב)** במעריך שגודלו לפחות ⁨`2^31`⁩, מסלול ⁨`INT`⁩ יכול לחזור בלי לעדכן את בית הזוגיות ⁨`$01`⁩, ואילו החזקה בבסיס שלילי משתמשת בבית הזה. **פתוח:** הסימן המתקבל בפועל והתלות במצב הקודם ב־⁨D32⁩. אין להניח בדיקת זוגיות מודרנית תקינה לכל מעריך עצום. [הדילוג ב־INT][int], [שימוש בזוגיות][power]

### השפעות RAM

**(ב־שחזור)** אזורי העבודה כוללים את ⁨FAC⁩ ב־⁨`$4F–$54`⁩, בית הדיוק הנוסף ⁨`$63`⁩, אזורים זמניים ⁨`$13–$16`⁩ ו־⁨`$40–$4E`⁩ ושדות ב־⁨`$55`⁩ וב־⁨`$5B–$65`⁩. ⁨`INT`⁩ יכולה לכתוב ב־⁨`$01`⁩; מסלול הזוויות משתמש גם ב־⁨`$0A`⁩. [מפת העבודה][rammap], [INT][int], [סינוס וטנגנס][sin]

**פתוח:** מפת כתיבה מלאה לכל אחת מהפונקציות, כולל שאריות לאחר שגיאה. הרשימה אינה אומרת שכל בית משתנה בכל קריאה.

## 2. ⁨`RND`⁩

### הזרע והחשבון

**(ב)** חמשת בתי האתחול הם ⁨`80 4F C7 52 59`⁩, אבל **המצב הפעיל אינו מספר צף בן חמישה בתים**:

- ⁨`$0115`⁩ מכיל בתחילה ⁨`$80`⁩ ואינו חלק מהמצב הפעיל המתעדכן.
- ⁨`$0116–$0119`⁩ מכילים מספר בלתי־חתום בן 32 סיביות, גבוה תחילה.
- המצב ההתחלתי הוא ⁨`$4FC75259`⁩, כלומר ⁨`1338462809`⁩. [הקצאה][rndram], [אתחול][rndinit], [שימוש][rnd]

**(ב)** בכל קידום מכפילים את המצב ב־**1088834987**, מוסיפים **95446411**, ושומרים את 32 הסיביות הנמוכות — חשבון מודולו **4294967296**. השמירה מתרחשת לפני נרמול ועיגול התוצאה המוחזרת. [מקור][rnd]

**(ב)** לשחזור המספר המוחזר נדרש גם בית דיוק: סיביות **40–47 של המכפלה בת 64 הסיביות, לפני הוספת הקבוע**. אם ערכו ⁨`e`⁩, הערך שלפני הנרמול והעיגול שקול ל־⁨`(מצב חדש + e/256)/4294967296`⁩. בית זה אינו נשמר בארבעת בתי הזרע. [מכפלה][multiply], [בחירת בית הדיוק][rnd], [נרמול ועיגול][normalize]

### משמעות הארגומנט

כל המסלולים בטבלה הם **(ב)** לפי [פענוח הארגומנט][rnd].

| ארגומנט | פעולה ותוצאה |
|---|---|
| ⁨`RND(0)`⁩ | מקדם את המצב ומחזיר שבר חדש; אינו מחזיר את התוצאה הקודמת. |
| חיובי, כולל ⁨`RND(1)`⁩ | לוקח תחילה ⁨`INT(n)`⁩; מקדם; מכפיל את השבר במספר השלם, מוסיף 1 ולוקח ⁨`INT`⁩. **חייבים לשמר את עיגולי הביניים.** |
| חיובי קטן מ־1 | החלק השלם אפס, ולכן מחזיר 1; הזרע מתקדם בכל זאת. |
| שבר חיובי גדול מ־1 | פועל לפי החלק השלם של הארגומנט. |
| שלילי, כולל שבר שלילי | משתמש במנטיסה המנורמלת בת 32 הסיביות כמצב התחלתי, מקדם ומחזיר שבר. אין קיטום לשלם לפני הזריעה. |

**(ב)** הסימן והמעריך אינם חלק מן הזרע שמופק מארגומנט שלילי. לכן ⁨`-1`⁩, ⁨`-2`⁩ ו־⁨`-.5`⁩ מתחילים אותו רצף. [זריעה][rnd]

**(ב, מסקנה מחישוב המסלול)** השבר במסלול אפס/שלילי גדול מאפס וקטן מאחד. גם כאשר המצב החדש אפס, בית הדיוק אינו אפס; במצב החדש ⁨`$FFFFFFFF`⁩ העיגול אינו מגיע לאחד. **אימות הקצוות על D32 פתוח.** [עדכון והמרה][rnd], [עיגול][normalize]

**תיקון חשוב: אין להבטיח ש־⁨`RND(1)`⁩ תמיד מחזירה 1.**

**(ב, מסקנה מחישוב המסלול)** מהזרע ⁨`$9758135C`⁩ מתקבל מצב חדש ⁨`$FFFFFFFF`⁩ ושבר ⁨`1−2^-32`⁩. במסלול החיובי, הוספת 1 מתעגלת ל־2 לפני ⁨`INT`⁩. לכן תחזית המקור היא **⁨`RND(1)=2`⁩** במקרה הזה; באותו מצב, ⁨`RND(2)`⁩ צפויה להחזיר 3. זו אינה תוצאת הרצה על חומרה. [כפל, חיבור ו־INT][rnd], [עיגול החיבור][addround]

מכאן שגם עבור גבול חיובי קטן אין לקבע כלל מוחלט של ⁨`1…INT(n)`⁩ בלי לשמר את מסלול החשבון המקורי.

### שגיאות וזיכרון

**(ב)** מתקבל כל ארגומנט מספרי מיוצג, ללא הגבלת בית או כתובת. בקלט מחרוזת, בדיקת הטיפוס המאוחרת יכולה להפיק ⁨`TM`⁩ **לאחר שהזרע כבר השתנה**. [מחולל][rnd], [בדיקת טיפוס][dispatch]

**(ב, חישוב לפי הקבועים)** מהאתחול הרגיל, קריאת ⁨`RND(0)`⁩ הראשונה משנה את ⁨`$0116–$0119`⁩ ל־⁨`7F 8F 2B FE`⁩; ⁨`$0115`⁩ נשאר ⁨`$80`⁩. [אתחול][rndinit], [קידום][rnd]

**(ב־שחזור)** העבודה משתמשת גם ב־⁨`$AB–$AE`⁩, ⁨`$13–$16`⁩ ובמצברים; במסלול החיובי גם באזור ⁨`$40–$44`⁩ ובבית ⁨`$01`⁩. [מכפלה][multiply], [מחולל][rnd], [מפה][rammap]

**(ב, השוואה)** זהו מחולל שונה מזה של ⁨BASIC-M6502⁩. במקור Microsoft יש כפל וחיבור במספר צף וערבוב בתי מנטיסה; חיובי מחזיר שבר. אפס מחזיר את התוצאה הקודמת בענפים הרגילים, ובחלופת ⁨`REALIO=3`⁩ משתמש במוני חומרה. [Microsoft RND][mrnd]

## 3. מחרוזות, המרה וקריאת מספרים

### תחומים ושגיאות משותפים

**(ב)** בהמרת פרמטר לבית נבדקים תחילה טיפוס מספרי וסימן לא־שלילי, ואז מוסר השבר. התוצאה השלמה חייבת להיות ⁨`0–255`⁩. לכן ⁨`255.9`⁩ מתקבל כ־255; ⁨`256`⁩ או מספר שלילי גורמים ⁨`FC`⁩; מחרוזת במקום מספר גורמת ⁨`TM`⁩. במיקום של ⁨`MID$`⁩ ושל ⁨`INSTR`⁩ גם אפס לאחר ההמרה גורם ⁨`FC`⁩. [המרה][intconvert], [המרת בית][byteconvert]

**(ב)** יצירת מחרוזת יכולה להפעיל איסוף. מחסור במקום לאחר האיסוף גורם ⁨`OS`⁩; מחסור במתאר זמני גורם ⁨`ST`⁩. שגיאת תחביר גורמת ⁨`SN`⁩. שגיאות בחישוב הארגומנטים יכולות להקדים אותן. [הקצאה ואיסוף][stringspace], [תחביר][syntax]

| פונקציה | תחום, תוצאה ושגיאות |
|---|---|
| ⁨`STR$(x)`⁩ | **(ב)** מספר; מחרוזת גורמת ⁨`TM`⁩. רווח מוביל לחיובי ולאפס, מינוס לשלילי, **ללא רווח מסיים**. דוגמאות: ⁨`" 0"`⁩, ⁨`" .5"`⁩, ⁨`"-.5"`⁩. [כניסה][str], [פורמט][format] |
| ⁨`VAL(s$)`⁩ | **(ב)** מחרוזת; מספר גורם ⁨`TM`⁩. ריקה מחזירה אפס. מפענחת תחילית מספרית: ⁨`"12XYZ"`⁩ נותנת 12; ⁨`"XYZ"`⁩ נותנת אפס. יכולה להפיק ⁨`OV`⁩, ובמסלול האוקטלי גם ⁨`SN`⁩. [VAL][val], [מפענח][parse] |
| ⁨`ASC(s$)`⁩ | **(ב)** ערך הבית הראשון, ⁨`0–255`⁩; אין הגבלה לשבע סיביות. מחרוזת ריקה: ⁨`FC`⁩. מספר: ⁨`TM`⁩. [מקור][lenchr] |
| ⁨`CHR$(n)`⁩ | **(ב)** המרת בית לפי הכלל המשותף; מחרוזת באורך 1. גם ⁨`CHR$(0)`⁩ באורך 1. [מקור][lenchr] |
| ⁨`LEN(s$)`⁩ | **(ב)** אורך ⁨`0–255`⁩ מתוך המתאר. בית אפס בתוך התוכן אינו מפסיק את הספירה. מספר: ⁨`TM`⁩. [מקור][lenchr] |
| ⁨`LEFT$(s$,n)`⁩ | **(ב)** עד ⁨n⁩ תווים מתחילת המחרוזת; אפס מחזיר ריק; בקשה ארוכה מאורך המחרוזת מחזירה את כולה. טיפוס ראשון שגוי גורם ⁨`TM`⁩ לפני בדיקת הפרמטר המספרי. [חיתוך][slice], [סדר בדיקה][dispatch] |
| ⁨`RIGHT$(s$,n)`⁩ | **(ב)** אותם תחומים ושגיאות, מסוף המחרוזת. [מקור][slice] |
| ⁨`MID$(s$,p[,n])`⁩ | **(ב)** מיקום מתחיל ב־1. אפס, כולל שבר חיובי קטן מ־1, גורם ⁨`FC`⁩. מיקום מעבר לסוף מחזיר ריק. אורך חסר שקול לבקשת 255 תווים; אפס מחזיר ריק; החיתוך נעצר בסוף. [מקור][slice] |
| ⁨`INSTR([p,]s$,t$)`⁩ | **(ב)** מיקום ברירת מחדל 1; התאמת בתים; מחזירה מיקום ראשון או אפס. בודקת מיקום מעבר לסוף **לפני** מחרוזת חיפוש ריקה. לכן ⁨`INSTR("","")=0`⁩, ⁨`INSTR(4,"ABC","")=0`⁩, אך ⁨`INSTR(2,"ABC","")=2`⁩. מיקום אפס: ⁨`FC`⁩; תוכן שאינו מחרוזת: ⁨`TM`⁩. [מקור][instr] |
| ⁨`STRING$(n,c)`⁩ | **(ב)** ⁨n⁩ עותקים של בית. מספר ב־⁨c⁩ מומר לבית; מחרוזת מספקת את הבית הראשון. מחרוזת ריקה גורמת ⁨`FC`⁩ **גם כש־⁨`n=0`⁩**. אפס עם תו חוקי מחזיר ריק. [מקור][stringfn], [בדיקת ריק][lenchr] |
| ⁨`HEX$(x)`⁩ | **(ב)** במסלול מספרי: ⁨`0≤x<65536`⁩, הסרת שבר. שלילי או 65536 ומעלה: ⁨`FC`⁩. אותיות ⁨`A–F`⁩ גדולות; בלי ⁨`&H`⁩, רווח או אפסים מובילים. אפס מחזיר ⁨`"0"`⁩. [המרה][address], [HEX$][hex] |

**פתוח — ⁨`HEX$`⁩ עם מחרוזת:** אין להבטיח ⁨`TM`⁩. **(ב)** השיגור אינו בודק מספר מראש, הפונקציה משתמשת בשדות ⁨FAC⁩, וביציאה היא עוקפת את בדיקת הטיפוס המאוחרת. התוצאה עשויה להיות תלויה במצב הקודם. [שיגור][dispatch], [HEX$][hex]

### פורמט ⁨`STR$`⁩

**(ב)** בתצורת חמשת הבתים מופקות עד תשע ספרות משמעותיות. אפסים מיותרים בסוף השבר מוסרים, וכך גם נקודה ללא ספרות אחריה. אין אפס לפני הנקודה במספר כגון ⁨`.5`⁩. בכתיב מדעי מופיעים ⁨`E`⁩, סימן מעריך ושתי ספרות מעריך. [ממיר הפלט][format]

**(ב־שחזור)** בתצורת ⁨`ADDPRC=1`⁩, הסף התחתון הרגיל לכתיב קבוע הוא ⁨`.01`⁩, כולל ⁨`.01`⁩; הסף העליון הרגיל הוא ⁨`10^9`⁩. הבחירה נעשית אחרי שינוי קנה מידה ועיגול — אין להחליפה בהשוואה פשוטה לערך המקורי ליד הגבולות. **פתוח ל־D32:** הסתירה לסף ⁨`.001`⁩ שכבר מתועדת במסמכי הפרויקט. [תנאי הפורמט][format], [תצורה][config]

### ⁨`&H`⁩, ⁨`&O`⁩, ⁨`&`⁩ ו־⁨`VAL`⁩

- **(ב)** ⁨`&H`⁩ בוחר בסיס 16; ⁨`&O`⁩ ו־⁨`&`⁩ ללא אות בוחרים בסיס 8. התוצאה נבנית כמספר בלתי־חתום בן 16 סיביות. גלישה בצבירת ספרה גורמת ⁨`OV`⁩. [מקור][radix]
- **(ב)** ⁨`VAL`⁩ מגיעה למסלול הזה כאשר ⁨`&`⁩ הוא תחילת המספר לאחר דילוג הרווחים הראשוני. אחרי סימן עשרוני אין בדיקה מחודשת של ⁨`&`⁩: ⁨`VAL("-&H10")`⁩ ו־⁨`VAL("+&H10")`⁩ מחזירות אפס. בביטוי רגיל, ⁨`-&H10`⁩ הוא מינוס אונרי של 16. [מפענח][parse], [ביטוי][eval]
- **(ב)** בהקסדצימלי, תו שאינו ספרה או אות גדולה ⁨`A–F`⁩ מסיים את הקריאה. לכן ⁨`VAL("&H1G")=1`⁩. קידומת ללא ספרות, כגון ⁨`VAL("&H")`⁩ או ⁨`VAL("&O")`⁩, מחזירה אפס. בתוכנית, יתר הטקסט עדיין כפוף לבדיקת תחביר. [מקור][radix]
- **(ב)** **חריגה בפענוח אוקטלי:** נדחית ספרה גדולה מ־8, ולא גדולה מ־7. לכן ⁨`VAL("&O8")=8`⁩, ואילו ⁨`VAL("&O9")`⁩ גורמת ⁨`SN`⁩. צבירת 8 בקבוע ארוך אינה בהכרח חשבון עקבי, משום שהמסלול מניח ספרה חוקית ויכול לאבד נשיאה. **אימות D32 פתוח.** [בדיקת ספרה וצבירה][radix]
- **(ב)** במסלול העשרוני נקראים סימן, נקודה ו־⁨`E`⁩ עם סימן מעריך. ספרות המעריך מצטברות בבית בן 8 סיביות ללא בדיקת גלישה בשלב הצבירה. **פתוח:** תוצאות מדויקות לקלטים כגון ⁨`"1E999"`⁩; אין להניח ממיר מודרני. [מפענח][parse]

### השפעות RAM

**(ב; הכתובות בחלקן ב־שחזור)** יצירת מחרוזת יכולה לשנות:

| כתובת | משמעות |
|---|---|
| ⁨`$23–$24`⁩ | גבול שטח המחרוזות הפנוי |
| ⁨`$25–$26`⁩ | כתובת הקצאה |
| ⁨`$56–$5A`⁩ | מתאר עבודה |
| ⁨`$0B–$0C`⁩, ⁨`$0D–$0E`⁩ | מצביעי מתארים זמניים |
| החל מ־⁨`$01A9`⁩ | אזור מתארים זמניים |
| ⁨`$06`⁩ | ⁨`$FF`⁩ לתוצאת מחרוזת |
| ⁨`$52–$53`⁩ | מצביע למתאר התוצאה |

בהקצאת ⁨L⁩ תווים הגבול יורד ב־⁨L⁩, והתו הראשון בכתובת הגבול החדש ועוד 1. [הקצאה ומתארים][stringspace], [מפה][rammap]

**(ב)** גם ⁨`LEN`⁩, ⁨`ASC`⁩, ⁨`VAL`⁩ ו־⁨`INSTR`⁩ יכולות לשחרר מתאר זמני ובמקרה המתאים להחזיר שטח תווים. איסוף יכול להזיז מחרוזות ולעדכן מתארים. [שחרור][lenchr], [איסוף][stringspace], [INSTR][instr]

**(ב)** ⁨`VAL`⁩ כותבת זמנית אפס בבית **שאחרי תוכן המחרוזת**, ומחליפה זמנית את מצביע הטקסט ⁨`$A6–$A7`⁩. בחזרה תקינה שניהם משוחזרים. שגיאת פענוח אינה חוזרת דרך השחזור המקומי; **אין להבטיח שהבית שוחזר אחרי כשל**. [מקור][val]

**(ב)** ⁨`STR$`⁩ ו־⁨`HEX$`⁩ בונות תחילה טקסט בחוצץ הפלט הנמוך ומעתיקות אותו לשטח המחרוזות. הפענוח והפורמט משתמשים גם ב־⁨FAC⁩ ובבתי עבודה ובהם ⁨`$45–$48`⁩. **פתוח:** מפת כתיבות מלאה לכל פונקציה. [STR$][str], [HEX$][hex], [מפענח][parse], [מפה][rammap]

### ⁨`PEEK`⁩, ⁨`POS`⁩, ⁨`MEM`⁩ ו־⁨`VARPTR`⁩

| פונקציה | התנהגות |
|---|---|
| ⁨`PEEK(x)`⁩ | **(ב)** מספר ⁨`0≤x<65536`⁩; מסירה שבר ומחזירה בית ⁨`0–255`⁩. שלילי או 65536 ומעלה גורמים ⁨`FC`⁩. [מקור][address] |
| ⁨`POS(d)`⁩ | **(ב)** אחרי המרה לשלֵם: 0 למסך, ⁨`-1`⁩ לקלטת, ⁨`-2`⁩ למדפסת. במסך: עמודה ⁨`0–31`⁩, לפי חמש הסיביות הנמוכות של כתובת הסמן. במדפסת: עמודת המדפסת. בקלטת פתוחה לפלט: **0**. קלטת סגורה: ⁨`NO`⁩; פתוחה לקלט: ⁨`FM`⁩. [POS][pos], [פרטי התקן][devices] |
| ⁨`MEM`⁩ | **(ב)** ללא ארגומנט. בדיוק ⁨`(S_entry−STREND) mod 65536`⁩, כתוצאה בלתי־חתומה. ⁨`S_entry`⁩ הוא מצביע המחסנית **בכניסה לפונקציה עצמה**; ⁨`STREND`⁩ ב־⁨`$1F–$20`⁩. אין תיקון לכתובת החזרה ואין איסוף מחרוזות. [דגימת המחסנית][mem], [חיסור][memext] |
| ⁨`VARPTR(v)`⁩ | **(ב)** שם משתנה או איבר מערך, לא ביטוי חופשי. מספר פשוט: כתובת בית המעריך, שני בתים אחרי תחילת הרשומה. מחרוזת: כתובת המתאר, לא התווים. איבר מערך: תחילת תא הערך בן חמשת הבתים. התוצאה כתובת בלתי־חתומה. [VARPTR][varptr], [משתנים][variables], [מערכים][arrays] |

**פתוח — ⁨`PEEK`⁩ עם מחרוזת:** אין להבטיח ⁨`TM`⁩. **(ב)** אין בדיקת טיפוס לפני המרת הכתובת, והחזרת המספר מאפסת את דגל הטיפוס. שאריות ⁨FAC⁩ יכולות להשפיע על הכתובת או השגיאה. [המרה][address], [איפוס טיפוס בהחזרה][mem], [שיגור][dispatch]

**(ב)** ⁨`POS`⁩ ממירה מספר התקן באמצעות ⁨`INT`⁩, כלומר כלפי מטה. ההמרה מקבלת ⁨`-32768`⁩ בדיוק ועד מספרים הקטנים מ־32768. מחרוזת: ⁨`TM`⁩; חריגה מהתחום: ⁨`FC`⁩; מספר שלם שאינו התקן חוקי: ⁨`DN`⁩. [המרה][intconvert], [בדיקת התקן][devicearg]

**(ב)** ⁨`VARPTR`⁩ של משתנה חסר יכולה **להקצות אותו ואז להחזיר ⁨`FC`⁩**, מפני שסוף המשתנים/המערכים השתנה. אין ביטול ההקצאה. ייתכנו הזזת מערכים ושינוי ⁨`$1D–$20`⁩. [בדיקת השינוי][varptr], [הקצאה][variables]

**(ב)** שגיאות נוספות של ⁨`VARPTR`⁩: ⁨`SN`⁩ בשם או בסוגריים; ⁨`TM`⁩ באינדקס מחרוזת; ⁨`FC`⁩ באינדקס שלילי או מחוץ לתחום ההמרה; ⁨`BS`⁩ בגבול מערך או במספר ממדים; ⁨`OM`⁩ יכולה להקדים את ⁨`FC`⁩ אם ההקצאה נכשלת. [אינדקסים][intconvert], [מערכים][arrays]

### ⁨`TIMER`⁩, ⁨`INKEY$`⁩ ו־⁨`JOYSTK`⁩

| פונקציה | התנהגות ושגיאות |
|---|---|
| ⁨`TIMER`⁩ | **(ב)** נקראת ללא סוגריים ומחזירה שלם ⁨`0–65535`⁩. השמה מקבלת ⁨`0≤x<65536`⁩ ומסירה שבר. שלילי או חריגה: ⁨`FC`⁩; מחרוזת: ⁨`TM`⁩. [מקור][timer] |
| ⁨`INKEY$`⁩ | **(ב)** ללא ארגומנט. אם ⁨`$87`⁩ אינו אפס, משתמשת בבית השמור; אחרת סורקת מקלדת. מאפסת ⁨`$87`⁩. קוד לא־אפס מוחזר כמחרוזת בת בית אחד; אפס כמחרוזת ריקה. הקוד נכתב גם ב־⁨`$53`⁩. [מקור][inkey] |
| ⁨`JOYSTK(n)`⁩ | **(ב)** מספר ⁨`0≤n<4`⁩ עם הסרת שבר. חריגה: ⁨`FC`⁩; מחרוזת: ⁨`TM`⁩. **רק אינדקס 0 מרענן את כל ארבע הדגימות**; 1–3 מחזירים ערך שמור. [מקור][joystick] |

**(ב)** ⁨`TIMER`⁩ משתמשת ב־⁨`$0112–$0113`⁩, גבוה תחילה; ההגדלה מודולו 65536. ⁨`$0114`⁩ אינו נכתב במסלולי הקריאה, ההשמה וההגדלה האלה. **פתוח ל־D32:** הסתירה על הבית השלישי נשארת; אין להסיק מהמקור קצב ⁨PAL⁩. [מונה][timer]

**(ב)** ⁨`INKEY$`⁩ יכולה לשנות גם מצב סריקה וחזרת מקש כשנדרשת סריקה. יצירת התוצאה כפופה למנגנון המחרוזות; אין להבטיח שהיא חסינה משגיאות הקצאה. [סריקה][keyboard], [הקצאה][stringspace]

**(ב)** ערכי המוט נשמרים ב־⁨`$015A–$015D`⁩. המדידה הטבעית מפיקה ⁨`0–63`⁩; הרענון מודד ערוצים בסדר ⁨`3,2,1,0`⁩. בקריאה שמורה מוחזר הבית ללא מסכה לשש סיביות, ולכן ⁨POKE⁩ יכול לגרום להחזרת ערך עד 255. [מדידה][joyhardware], [קריאה][joystick]

### ⁨`USR0–USR9`⁩ ו־⁨`DEF USR`⁩

**(ב)** נבחרת ספרה אחת ⁨`0–9`⁩; בהשמטתה נבחר 0. בסיס הטבלה הוא המצביע ב־⁨`$B0–$B1`⁩, שמאותחל ל־⁨`$0134`⁩. כל יעד תופס שני בתים, גבוה תחילה; ברירת המחדל ליעד ⁨n⁩ נמצאת ב־⁨`$0134+2n`⁩. אפשר להזיז את הטבלה באמצעות המצביע. באתחול כל עשרת היעדים מובילים ל־⁨`FC`⁩. [בחירה והגדרה][usr], [אתחול][usrinit]

**(ב)** ⁨`DEF USRn=address`⁩ מקבלת מספר ⁨`0≤address<65536`⁩ ומסירה שבר. חריגה: ⁨`FC`⁩; מחרוזת: ⁨`TM`⁩. אין בדיקה שהכתובת מכילה שגרה תקינה. [הגדרה][usr], [המרת כתובת][address]

| סוג הארגומנט בקריאה | מצב הכניסה לשגרה |
|---|---|
| מספר | **(ב)** ⁨`A=0`⁩, ⁨`X=$004F`⁩; הערך ב־⁨FAC⁩. |
| מחרוזת | **(ב)** ⁨`A=$FF`⁩; ⁨X⁩ מצביע למתאר. מתאר זמני משוחרר במסלול ההכנה לפני העברת השליטה. |

מקור: [העברת הארגומנט][usr].

**(ב־שחזור)** בכניסה מספרית: מעריך ב־⁨`$4F`⁩; ארבעה בתי מנטיסה ב־⁨`$50–$53`⁩ עם הסיבית המובילה מפורשת; סימן ב־⁨`$54`⁩; בית דיוק נוסף ב־⁨`$63`⁩. במתאר מחרוזת, האורך בהיסט 0 וכתובת התוכן בהיסטים ⁨`2–3`⁩. [טעינת FAC][fac], [מתאר][varptr], [מפה][rammap]

**(ב)** אין בחזרה המרה אוטומטית של ⁨D⁩ או ⁨X⁩ למספר BASIC. התוצאה תלויה ב־⁨FAC⁩ ובדגל הטיפוס. **פתוח:** חוזה מלא לחזרת מחרוזת ולשימור כל האוגרים. [מסלול הקריאה][usr]

### ⁨`EOF`⁩, ⁨`POINT`⁩ ו־⁨`PPOINT`⁩

| פונקציה | התנהגות |
|---|---|

**(ב)** ⁨`POS`⁩ ו־⁨`EOF`⁩ משחזרות את מספר ההתקן לאחר הצלחה. ⁨`POS`⁩ מעדכנת פרמטרי פלט, ובהם עמודת העבודה ⁨`$6C`⁩. **פתוח:** מצב כל שדות ההתקן לאחר כשל. [POS][pos], [EOF][eof], [פרמטרים][devices]

## מה שונה מ־⁨BASIC-M6502⁩

- **(ב)** מחולל ⁨`RND`⁩, פורמט המצב ומשמעות הארגומנטים שונים. [Dragon][rnd], [Microsoft][mrnd]
- **(ב)** אפס בחזקה שלילית: ⁨Dragon⁩ מחזיר ⁨`/0`⁩; מסלול Microsoft שנבדק מחזיר אפס. [Dragon][power], [Microsoft][mpower]
- **(ב)** ⁨`TAN`⁩ עם קוסינוס מחושב אפס: ⁨Dragon⁩ מחזיר ⁨`OV`⁩; מסלול Microsoft מגיע לחילוק באפס. [Dragon][tan], [Microsoft][mtan]
- **(ב)** פענוח ⁨`&H / &O / &`⁩ נוסף ב־⁨Dragon⁩; אינו נמצא במפענח המספרים המקביל שנבדק ב־Microsoft. [Dragon][parse], [Microsoft][mparse]
- **(ב)** הטיפול בדיוק נוסף ב־⁨`EXP`⁩ שונה. **טבלאות המקדמים בחמשת הבתים וקדימות האופרטורים זהות.** [Dragon EXP][exp], [Microsoft EXP][mexpround], [טבלאות LOG][mlog], [EXP][mexp], [SIN][msin], [ATN][matn], [קדימות][mprecedence]

## פרטים פתוחים וניסויי הכרעה

כל הניסויים הבאים **טרם הורצו על D32 במסגרת המחקר הזה**. מקרים שמפיקים שגיאה נבדקים בריצות נפרדות.

| הפער | ניסוי מוצע |
|---|---|
| תוצאות מתמטיות מדויקות בחמשת הבתים | התוכנית להלן; להחליף את הביטוי בכל פונקציה ובמקרי הגבול. |
| גבולות ⁨`EXP`⁩ | לבדוק בנפרד ⁨`PRINT EXP(88)`⁩, ⁨`EXP(88.1)`⁩, ⁨`EXP(-88)`⁩, ⁨`EXP(-88.1)`⁩, ואז לצמצם את התחום ולצלם בתי תוצאה. |
| זוגיות מעריך עצום | ⁨`A=INT(1):PRINT (-1)^2147483648`⁩; לחזור עם ⁨`INT(2)`⁩ ועם המעריך ⁨`2147483649`⁩. |
| שגיאת טיפוס מאוחרת | לבדוק בנפרד ⁨`SGN("X")`⁩, ⁨`LOG("X")`⁩, ⁨`SQR("X")`⁩, ⁨`EXP("X")`⁩ ו־⁨`RND("X")`⁩, אחרי פעולה מספרית קודמת מתועדת. |
| חריגת ⁨`RND(1)`⁩ | תוכנית הזרע המפורשת להלן; תחזית המקור היא 2. |
| זריעה משבר שלילי | להשוות רצפים לאחר ⁨`RND(-1)`⁩, ⁨`RND(-2)`⁩ ו־⁨`RND(-.5)`⁩; לצלם גם ⁨`$0115–$0119`⁩. |
| ספי ⁨`STR$`⁩ | ⁨`PRINT "[";STR$(.001);"][";STR$(.01);"][";STR$(.00999999999);"]"`⁩; לבדוק גם ⁨`999999999`⁩ ו־⁨`1E9`⁩. |
| הספרה 8 באוקטלי | בנפרד: ⁨`PRINT VAL("&O8")`⁩, ⁨`PRINT VAL("&O9")`⁩, ⁨`PRINT VAL("&O378")`⁩; לחזור כקבועים ללא ⁨`VAL`⁩. |
| גלישת מעריך עשרוני | בנפרד: ⁨`PRINT VAL("1E255")`⁩, ⁨`VAL("1E256")`⁩, ⁨`VAL("1E257")`⁩. |
| ⁨`HEX$`⁩ ו־⁨`PEEK`⁩ עם מחרוזת | בריצות נקיות: ⁨`A=0:PRINT HEX$("A")`⁩ ואחר כך עם ⁨`A=1E20`⁩; בדיקה מקבילה ל־⁨`PEEK("A")`⁩. |
| מחרוזות ריקות וסדר בדיקות | ⁨`PRINT INSTR("","");INSTR(4,"ABC","");INSTR(2,"ABC","")`⁩; בנפרד ⁨`PRINT LEN(STRING$(0,""))`⁩ ו־⁨`PRINT MID$("ABC",.5)`⁩. |
| שחזור אחרי כשל ב־⁨`VAL`⁩ | ליצור ⁨`A$="1E99"`⁩, לאתר דרך המתאר את הבית שאחרי התוכן, לתעד אותו, לבצע ⁨`VAL(A$)`⁩ ולבדוק שוב אחרי השגיאה. הבדיקה מבחינה רק אם הבית המקורי אינו אפס. |
| הקצאה לפני ⁨`FC`⁩ ב־⁨`VARPTR`⁩ | אחרי ⁨`NEW`⁩: ⁨`PRINT VARPTR(QQ)`⁩; אחרי השגיאה לחזור על אותה פקודה ולמדוד את מצביעי סוף המשתנים. |
| ⁨`TIMER`⁩ והבית השלישי | ⁨`TIMER=16384:PRINT PEEK(274);PEEK(275);PEEK(276):PRINT TIMER`⁩. למדוד גלישה וקצב ⁨PAL⁩ בנפרד. |
| ערך מוט שמור | ⁨`POKE 347,200:PRINT JOYSTK(1)`⁩; אחר כך ⁨`PRINT JOYSTK(0);JOYSTK(1)`⁩. |
| מקש שמור | ⁨`POKE 135,65:A$=INKEY$:PRINT A$;PEEK(135)`⁩. |
| חיתוך קואורדינטות | ⁨`PMODE 4,1:PCLS:PRINT PPOINT(256,192);PPOINT(255,191)`⁩. |
| ⁨`MEM`⁩ | התוכנית להלן בודקת הפרש במחסנית; אינה קובעת ערך מוחלט לכל אתר קריאה. |
| חוזה ⁨`USR`⁩ המלא | הכותב יכין שגרת ניסוי עצמאית ששומרת את ⁨A/X/FAC⁩ בכניסה ומחזירה תוצאה ידועה. הקורא אינו מספק מימוש או בתי הוראות. |
| כל בתי העבודה והבדלי הדגמים | נדרש צילום בנקודת זמן מוגדרת, בשני הדגמים בנפרד. תוכנית BASIC שמצלמת בעצמה משנה את ⁨FAC⁩, המחסנית ומצביעים; היא אינה יכולה לבדה להוכיח את כל שאריות העבודה. |

**בדיקת בתי תוצאה מספרית:**

```basic
10 A=SIN(1)
20 P=VARPTR(A)
30 FOR I=0 TO 4
40 PRINT HEX$(PEEK(P+I));
50 NEXT I
```

**בדיקת גבול ⁨`RND(1)`⁩ — תחזית מקור בלבד: 2:**

```basic
10 POKE 278,151:POKE 279,88
20 POKE 280,19:POKE 281,92
30 PRINT RND(1)
```

**בדיקת תלות ⁨`MEM`⁩ במחסנית:**

```basic
10 A=0:B=0
20 A=MEM
30 GOSUB 60
40 PRINT A-B
50 END
60 B=MEM:RETURN
```

**נותרו פתוחים:** אישור התנהגות ⁨D32⁩ לכל ממצא (ב), תוצאות מתמטיות מדויקות בכל סיבית, ספי גלישה ועיגול מלאים, סדר כל השגיאות, חוזה ⁨USR⁩ המלא ומפת כתיבות מלאה לכל פונקציה. אין בדוח בסיס לקביעה גורפת ש־⁨D32⁩ ו־⁨D64⁩ זהים בנושאים האלה.
